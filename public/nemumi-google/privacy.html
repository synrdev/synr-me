プライバシーポリシー | gws CLI

最終更新日：2026年10月24日

このポリシーはgws CLIに適用します。

取得・利用

本人の同意に基づき、アカウントの基本情報、Gmailのメール、Calendarの予定、Driveのファイルを読み取り、依頼された検索・整理・要約などに使用します。Gmail・Calendar・Driveへの権限は読み取り専用です。

共有・保存

利用者が承認した連携サービスやAIサービスへ、依頼の実行に必要な範囲で送信する場合があります。データへのアクセスを制限し、認証情報は暗号化して保管します。保存データやバックアップは、利用者が削除するまで残る場合があります。

広告、販売、汎用AIモデルの学習には使用しません。Googleデータの利用・転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

解除・削除

Googleアカウントの接続管理からアクセスを取り消せます。保存済みデータやバックアップは別途削除が必要です。削除については下記へお問い合わせください。
